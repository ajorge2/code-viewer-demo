Decision evidence · frozen before review

More coverage was possible. The quality bar said no.

CodeArchitect maps code components to a learned software-concept taxonomy. This evaluation asked whether its semantic acceptance threshold could safely move from 0.72 to 0.62. The decision rule was frozen first; method-blinded human review supplied the labels afterward.

The threshold stayed at 0.72.

The candidate nearly doubled accepted coverage, but the primary-metric gain could not override either quality failure. The system abstains more often instead of presenting a broader set of lower-confidence labels as reliable.
