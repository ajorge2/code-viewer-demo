Add this command as a local stdio MCP server in your AI app. Place a database at databases/shop/shop.sqlite and use shop as its ID. Your model writes SQL; the server does not call another model.

What “local” means for privacy
These MCP tools do not save request or response content, enable telemetry, or call a model provider. They return selected evidence to your AI host. That host may retain it or send it to its model provider under its own policy.
SQLHarness opens databases in the folder you select in read-only mode. Query inputs, result rows, and validation receipts are not saved by the MCP server. Your AI client generates SQL; the server does not call another model.
