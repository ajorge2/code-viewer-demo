# SQLHarness MCP distribution

This is the minimal MCP distribution of Andrew Jorge's [SQLHarness](https://github.com/ajorge2/SQLHarness). It reuses the Python database authority, SQLGlot validation and bounded read-only execution. Research/model-generation dependencies are omitted. The public CodeArchitect page exposes sample data; an explicit local database root is available over stdio only. No model calls or model credentials are required.
